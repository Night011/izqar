# Скриншоты IZQAR для README и жюри

Используйте только снимки реально работающего локального приложения. Не генерируйте изображения интерфейса и не ретушируйте результаты моделей.

## Перед съёмкой

1. Запустите API и React по [README](../../README.md#быстрый-запуск).
2. Войдите с локальным API-ключом; ключ, `.env`, адреса дисков, консоль и DevTools не должны попадать в кадр.
3. В Dashboard запустите demo-сценарии: normal, new recipient, fan-in, chain и cycle.
4. Откройте ML Analytics и дождитесь Registry. Unified в текущем состоянии должна быть помечена `validation only`.

| Имя файла | Экран | Проверка перед сохранением |
