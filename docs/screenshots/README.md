# Скриншоты IZQAR для README и жюри

Используйте только снимки реально работающего локального приложения. Не генерируйте изображения интерфейса и не ретушируйте результаты моделей.

## Как сняты текущие снимки

1. API и React запущены по [README](../../README.md#быстрый-запуск), база пересоздана пустой.
2. Демо-данные добавлены скриптом `scripts/seed_demo.py` (шесть сценариев + одно расследование).
3. Вход выполнен локальным API-ключом; ключ, `.env` и абсолютные пути в кадр не попали.
4. Снято в десктопном Chrome 1724×861 (карточка расследования — full page).

## Правила для новых снимков

1. Пометка демо-режима видна; API-ключ, `.env`, консоль и DevTools скрыты.
2. Нет `isFraud`, `isFlaggedFraud` и готовых меток в таблицах.
3. Метрики читаемы и совпадают с `backend/models/*.metrics.json`.
4. Unified подписан как эксперимент/validation-only.
5. Граф подписан как сигнал для расследования, не доказательство.
