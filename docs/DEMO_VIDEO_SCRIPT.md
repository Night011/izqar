# IZQAR — сценарий демонстрационного видео (2–4 минуты)

Запись только реального приложения: локальный API + React-консоль на демо-данных
`scripts/seed_demo.py`. Никаких слайд-шоу и рендеров вместо интерфейса.
API-ключ в кадр не попадает: вход выполняется до старта записи.

## Подготовка (до записи)

1. `scripts/start_local.ps1` (API на `:8000`), затем `cd frontend; npm run dev` (`:5173`).
2. `python scripts\seed_demo.py` — 19 операций и одно расследование.
3. Войти ключом из `.env`; убедиться, что в кадре нет ключа, DevTools и терминала.
4. Окно браузера 1440×900, масштаб 100%, тёмная тема, курсор виден.

## Технические требования к записи

- 1440×900 или 1920×1080, 25–30 fps, H.264, звук — только если есть микрофон.
- Без ускорений и склеек внутри шага: зритель должен видеть, что интерфейс живой.
- В кадре нет `.env`, ключа, консоли, уведомлений и других окон.
- Длительность 2–4 минуты; короче — лучше.
- Файл: `docs/presentation/izqar-demo.mp4` (или ссылка на YouTube unlisted).

## Пост-обработка

1. Обрезать паузы ожидания, оставить 2–3 секунды после каждого перехода.
2. Подписи-титры только фактами из экрана (без обещаний).
3. В конце — статичный кадр с адресом репозитория и пометкой research MVP.
